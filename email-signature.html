How to add this signature to Gmail
  1. Make sure the logo is live first: commit and push the assets folder, then check https://claritymetrics.org/assets/logo-mark.png opens.
  2. Open this file in Chrome. Select everything inside the dashed box (click just before the logo, drag to the end), then copy.
  3. Gmail → Settings (gear) → See all settings → General → Signature → Create new → name it "Munjal" → paste.
  4. Under "Signature defaults", pick it for new emails and replies. Scroll down and click Save Changes.
